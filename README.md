# Atlas Roast — One-Page Coffee Brand Website

A minimalist, static one-page website for a specialty coffee brand designed for GitHub Pages.

---

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages (static hosting)

No frameworks, no backend, fully static.

---

## Project Structure

atlas-roast/
│
├── index.html        -> Main one-page website
├── styles.css        -> Global styles (design system)
├── script.js         -> UI interactions (smooth scroll, animations)
│
├── assets/
│   ├── images/       -> Hero, product, and client images
│   ├── icons/        -> SVG icons for features/UI
│   └── fonts/        -> Optional custom fonts
│
└── README.md

---

## Website Sections

### 1. Hero
- Brand name and headline
- Short positioning statement
- Primary call-to-action (CTA)
- Hero product image

---

### 2. Features
- 100% Arabica beans
- Fresh small-batch roasting
- Sustainable sourcing
- Premium quality control

---

### 3. Products (Roasts)
Three core coffee offerings:
- Signature Blend
- Dark Roast
- Ethiopia Single Origin

Each card includes:
- Name
- Short description
- Price
- Order CTA

---

### 4. Trusted Clients
- Café and hotel logos
- Short trust statement
- Social proof for credibility

---

### 5. About & Contact
Split layout section:
- Brand story and mission
- Contact form (name, email, message)
- Contact details (email, phone, location)

---

### 6. Footer
- Copyright notice
- Basic brand/legal information

---

## Design Principles

- Minimal and focused layout
- Strong visual hierarchy
- Coffee-inspired dark aesthetic
- Clean typography and spacing
- Mobile-first responsive design
- Subtle animations for polish
